# 🧬 Biomedical Research Suite - Local & Private

Une suite d'outils de recherche biomédicale complète, conçue pour fonctionner de manière **100% locale et privée**. Ce projet utilise des modèles de langage (LLM) locaux et un moteur de recherche anonymisé pour permettre une exploration scientifique sans compromettre la confidentialité des données.

## 🚀 Lancement Rapide (One-Click Launch)

Le projet est conçu pour être lancé avec un seul clic ou une seule commande. Le système détecte automatiquement s'il doit effectuer une **installation complète** (première fois) ou simplement **lancer l'agent**.

### Prérequis
*   [Docker](https://www.docker.com/products/docker-desktop/) installé et fonctionnel.
*   [Docker Compose](https://docs.docker.com/compose/) (inclus avec Docker Desktop).
